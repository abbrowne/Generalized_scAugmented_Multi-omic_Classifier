This project yielded a classifier that can be applied to gene-level -omics data with outcomes available.

An example run of the classifier using TCGA PAAD data can be followed in the "test_classifier_script.R" file.

The analysis was performed using R version 4.4.3 and the necessary libraries are indicated in the script, with custom functions located in the "Bioinformatic_functions.R" file.

Future efforts will focus on incorporating classifier results from multiple -omic sources and integrating them together.

Classifier development work can be found in the scClassifier_development_workflow.Rmd and Generalized_RNAseq_workflow.Rmd files, but it is recommended to start with the test_classifier_script.R file.
